# Автоматизация баскетбольного протокола (BPMN)

Пет-проект по проектированию IT-системы для ведения протокола баскетбольных матчей.

## 🎯 О проекте
**Проблема (AS IS):** Ведение игры на бумаге. Секретарь вручную считает фолы, очки и ошибается из-за человеческого фактора.
**Решение (TO BE):** Разработка веб-приложения, где секретарь только вводит данные, а всю математику и проверку лимитов (5 фолов) берет на себя Система.

## 🗄️ Схема базы данных (ERD)
Модель данных спроектирована для хранения информации о матчах, командах, игроках и событиях (фолы/очки).

**[Открыть схему базы данных](./ERDKBA.png)**

### Основные сущности:
*   **Team** — справочник команд.
*   **Player** — игроки, привязанные к командам (1:M).
*   **Match** — матчи (связь с командами через home/away team_id).
*   **Event** — журнал всех событий матча (очки, фолы).
*   **Protocol** — итоговая статистика по матчу и MVP.
